## Background

`cache_model_0/abis/DINTaskCoordinator.json` and `DINTaskAuditor.json` are hardhat artifacts last regenerated 2026-06-09. They are missing 67 ABI entries for the coordinator (104 vs. 170 in `foundry/src`) and 96 entries for the auditor (68 vs. 158), and carry the pre-foundry constructors. PR #171 regenerated the six bundled `dincli/abis/` files but explicitly left these alone because the manifest pins them by IPFS CID.

Any model owner or tool that follows `cache_model_0` as a reference and resolves task-contract ABIs through the manifest will hit ABI encoding mismatches on reward settlement, commit-reveal, seed-lock, encrypted-test-data, and dispute-resolution functions added in P3.

## Steps

### 1. Regenerate the ABI files from foundry/out

```bash
cd foundry && forge build
```

Copy the two artifacts from `foundry/out`:

```bash
cp foundry/out/DINTaskCoordinator.sol/DINTaskCoordinator.json cache_model_0/abis/DINTaskCoordinator.json
cp foundry/out/DINTaskAuditor.sol/DINTaskAuditor.json         cache_model_0/abis/DINTaskAuditor.json
```

These include both the ABI and the deployment bytecode (foundry full artifact format).

### 2. Update cache_model_0/manifest.json metadata

In the `task_contracts` block, for both `coordinator` and `auditor` entries, update:

- `"type"`: change `"hardhat-artifact"` → `"foundry-artifact"`
- `"compilation"` block: update to match foundry's build settings:
  ```json
  {
    "toolchain": "foundry",
    "solc": "0.8.28",
    "viaIR": true,
    "optimizer": false,
    "evmVersion": "cancun"
  }
  ```
  (Match the values in `foundry/foundry.toml`.)
- Leave `"address"` fields unchanged — addresses only change on a contract redeploy.

### 3. Re-pin both files to IPFS and update the CIDs

Upload each regenerated file to IPFS using the configured IPFS provider:

```bash
dincli ipfs upload cache_model_0/abis/DINTaskCoordinator.json
dincli ipfs upload cache_model_0/abis/DINTaskAuditor.json
```

Update the `cid` fields in `cache_model_0/manifest.json`'s `task_contracts` block to the new CIDs returned.
