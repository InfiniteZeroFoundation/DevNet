# Part B — Manifest paths can't leave the model's directory (#227) — PR 2

### B1. One shared helper

- Add `resolve_manifest_path(base_dir: Path, manifest_path: str | Path) -> Path` in one shared place (`dincli/cli/utils.py` or next to `ensure_file_exists`). It:
  - rejects an absolute `manifest_path` (`Path(manifest_path).is_absolute()`);
  - resolves `(base_dir / manifest_path).resolve()` and rejects it unless `is_relative_to(base_dir.resolve())`;
  - raises a clear error naming the manifest key and the offending path. It never re-anchors silently.
- **Symlinks:** `resolve()` follows them, so a symlink inside the cache dir that points outside is rejected. Keep it that way and say so in the PR.

### B2. Every call site goes through it

Replace each `<base> / Path(manifest[...]["path"])` with the helper:
- `dincli/cli/client.py:129-130`
- `dincli/cli/aggregator.py:336-337`, `:557-558`
- `dincli/cli/auditor.py:450-453`
- `dincli/cli/modelownerd/aggregation.py:399-400`
- `dincli/cli/modelownerd/auditor_batches.py:144`
- `dincli/cli/modelownerd/model.py:103-104`, `:219-220`
- the task-contract artifact path in `dincli/cli/context.py:316` (`model_base_path / artifact_rel_path`)

Grep for any others (`git grep -n '\["path"\]' dincli`) and list what you changed in the PR.

### B3. Backstop in `ensure_file_exists`

`ensure_file_exists` gets a containment check too. Give it the trusted base directory, or check against `CACHE_DIR` and the task directory it's called for, so a future call site that forgets the helper still can't write outside. Leave `_normalize_path`'s warning in place. It covers non-manifest paths and isn't the fix.

### B4. Tests

pytest, in the existing `monkeypatch` style (see `tests/test_ipfs_config.py`, `tests/test_dintoken.py`). No network, IPFS or Docker.
- **Helper:**
  - a normal relative path resolves inside the base;
  - an absolute path is rejected;
  - `../../x` is rejected;
  - a symlink inside the base pointing outside is rejected.
- **Call sites:** at least one per role (client, auditor, aggregator, model owner) plus the artifact path. A manifest with `"path": "/tmp/…/outside"` raises before `retrieve_from_ipfs` is called (monkeypatch it and assert it's never reached).
- **`ensure_file_exists` backstop:** a direct call with an outside path raises.
- **Break-then-fix:** bypass the helper at one call site, confirm its test fails, then restore.
