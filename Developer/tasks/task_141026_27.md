## Background

PR #109 (`fix/dp-sensitivity`) correctly changed the DP default from `clip_scope: per_layer` to `clip_scope: global` so that `noise_scale = noise_multiplier * clipping_norm` is calibrated against the actual combined L2 norm of all tensors — the sensitivity fix itself is sound.

However, `cache_model_0/manifest.json`'s `clipping_norm: 1.0` was never revisited after this change:

- Under **`per_layer`**: `clipping_norm: 1.0` bounded each tensor independently to norm 1.0 — a realistic bound for any one layer.
- Under **`global`**: `clipping_norm: 1.0` bounds the **combined** L2 norm (`sqrt(Σ ‖tensor_i‖²)`) to 1.0 — for a model with multiple floating tensors, the combined norm easily exceeds 1.0 even if no individual tensor's norm changes. This clips the reference model more aggressively than before and degrades training quality proportionally.

PR #109's tests use `build_small_state_dict` (synthetic tensors) and never exercise the real `cache_model_0` weights, so this is unverified on the actual model.

## Steps

### 1. Measure the combined L2 norm of the real cache_model_0 weights

Load the trained `state_dict` from `cache_model_0/` (the MNIST-style reference model) and compute the combined L2 norm:

```python
import torch, math

state_dict = torch.load("cache_model_0/<weights_file>")
combined_norm = math.sqrt(sum(t.norm().item() ** 2 for t in state_dict.values() if t.is_floating_point()))
print(f"Combined L2 norm: {combined_norm:.4f}")
```

Record this value in the PR description.

### 2. Run clip_state_dict with the current clipping_norm: 1.0

Apply the DP mechanism with `clipping_norm=1.0` and `clip_scope="global"`:

```python
from cid_services.client import clip_state_dict
clipped = clip_state_dict(state_dict, clipping_norm=1.0, clip_scope="global")
clipped_norm = math.sqrt(sum(t.norm().item() ** 2 for t in clipped.values() if t.is_floating_point()))
print(f"Clipped L2 norm: {clipped_norm:.4f}  (reduction: {(1 - clipped_norm/combined_norm)*100:.1f}%)")
```

### 3. Decide whether to retune

If the reduction is negligible (< 5%), `clipping_norm: 1.0` is acceptable as-is — update `cache_model_0/manifest.json` with a comment confirming this was verified.

If the reduction is significant (≥ 5%), retune `clipping_norm` to a value that allows the real weights to pass through with minimal clipping (< 5%). A typical approach: set `clipping_norm` to the 75th–90th percentile of the combined norm measured across a representative sample of trained `state_dict`s. Record the chosen value and the measurement in the PR description.

### 4. Add a real-weights test

Add a test to `tests/test_cache_client_dp.py` that:

- Loads the actual `cache_model_0` state_dict (using the existing model-loading path)
- Applies `clip_state_dict` with `clip_scope="global"` and the (possibly retuned) `clipping_norm`
- Asserts that the combined L2 norm post-clip is within 5% of the pre-clip norm (i.e. the model is not being significantly clipped under the new default)
